Contrast of the icon against what sits behind it, for each tone (with background="none") or backgroundTone (with soft / solid, using the same tone for both). Icons are graphics, so WCAG asks for 3:1; aim for 4.5:1 when the icon stands in for text.

Tones are CSS variables: these numbers are for this site's theme. Run node scripts/tone-contrast.mjs --css your-theme.css from a clone of the repo to measure yours.
